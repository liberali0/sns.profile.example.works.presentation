# [사용법]

1. 폴더를 통째로 발표 PC(또는 USB)에 복사하세요. index.html 과 images 폴더가 같은 곳에 있어야 합니다.
2. index.html 을 크롬(또는 엣지)으로 열면 인터넷 없이도 작동합니다.
3. 크롬에서 F11 을 누르면 전체 화면이 됩니다.
4. 조작
   - 프로필 사진 클릭: 스토리 5개 자동 재생
   - 하이라이트 동그라미 클릭: 하이라이트 재생
   - 스토리 화면 오른쪽/왼쪽 클릭 또는 키보드 → ←: 다음/이전
   - Esc 또는 X: 스토리 닫기
   - 스페이스바: 스토리·하이라이트 자동 넘김 멈춤/다시 재생 (멈추면 오른쪽 위에 ⏸ 표시)
   - 자동 넘김이 끝까지 가면 첫 장으로 돌아와 멈춤 상태가 됨 (스페이스바로 다시 재생)
   - 피드 사진 클릭: 게시물 화면(스크롤)
   - 게시물 화면에서 키보드 → ↓: 다음 게시물, ← ↑: 이전 게시물, Esc: 뒤로
   - 키보드 P (한글 상태면 ㅔ): 발표 모드 켜기/끄기
     발표 모드에서는 휴대폰이 오른쪽으로 가고, 왼쪽에 지금 화면에 맞는 설명이 나옵니다.
     (창 너비가 좁으면 설명이 숨겨지니 F11 전체 화면에서 쓰세요)

5. 숫자 키 바로가기 (어느 화면에서든)
   1: 스토리
   2: 랑아 하이라이트
   3: 호야 하이라이트
   4: 은향이 하이라이트
   5: 첫 번째 피드
   6: 두 번째 피드
   7: 세 번째 피드
   Esc: 메인(프로필) 화면으로
